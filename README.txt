REELS VIDEO - GITHUB PAGES

Isi folder ini di-upload ke root repository GitHub:
- index.html
- style.css
- app.js
- videos.json

Pengaturan:
- Video TIDAK autoplay saat halaman dibuka atau saat discroll.
- Video mulai hanya setelah pengguna menekan tombol Play atau area video.
- Setiap klik untuk memulai video akan membuka directlink di tab baru, lalu video diputar di tab website.
- Video otomatis dijeda saat pengguna scroll ke video lain.
- Suara awalnya mati; pengguna bisa mengaktifkan lewat tombol suara.

Aktifkan GitHub Pages:
Settings > Pages > Deploy from a branch > main > /(root) > Save.

Catatan: browser dapat memblokir tab baru jika pengaturan popup membatasi situs. Gunakan hanya video yang Anda miliki atau punya izin untuk dipublikasikan.
